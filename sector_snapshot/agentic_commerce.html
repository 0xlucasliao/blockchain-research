Agentic commerce

April 2026 · Agents paying on behalf of users: what is already shippable, and which autonomous commerce loops are still gated.

Flows possible today

Human-present wallet payment
User → wallet app → sign tx → chain → merchant / PSP
Agent with virtual card + spend policy
User sets limit → agent runtime → issuer / BIN sponsor → card network → Web2 merchant
Delegated payment via exchange or custodial API
User API key / OAuth → bot → custodian executes transfer → receipt to app
MCP tool calls that trigger a signed human step
Agent proposes pay → user approves in wallet → transaction broadcast

High demand · not yet practical

Human-not-present spend at arbitrary merchants with chain-native USDC
Agent → merchant chain address → delivery / dispute semantics

Why blocked: Few merchants expose chain checkout; AP2 / FIDO human-not-present rails not ubiquitous; reversibility and dispute policy not standardised on-chain.

One policy graph across bank, card, and chain limits
User rule set → enforced on issuer + chain + agent host

Why blocked: Identity and policy silos; no shared attestation consumers across PSP, chain, and agent vendors yet.

Autonomous procurement with corporate treasury on public L1/L2
Agent → PO match → on-chain settlement → ERP posting

Why blocked: Corporate treasury policy, tax, and audit tooling expect bank statements; ERP connectors for chain events are immature.
